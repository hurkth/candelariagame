# Promesa de Candelaria

Juego 3D en el navegador inspirado en la Festividad de la Virgen de la Candelaria (Puno). Hecho con three.js, sin build.

| Día | Nivel |
|---|---|
| 1 · Llegada de bandas | Recoge 6 instrumentos por el centro y llévalos a la banda (ojo con el soroche) |
| 2 · Ensayo general | Ritmo con flechas al golpe del bombo |
| 3 · La tribuna | Plataformas tipo Donkey Kong: el Supay lanza bombos |
| 4 · Parada | Runner por la calle: esquiva, junta aplausos, marca el paso |

## Correr local
```bash
npx serve .
```

## Deploy
Sitio estático: en Vercel, importa el repo con Framework Preset **Other**, sin build command ni output directory.
